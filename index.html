Hlavní projekt
Hardware & IoT řešení

Systém pro půjčování powerbank

Koncept a technický návrh automatizované sdílené stanice na půjčování powerbank pro studenty a návštěvníky veřejných prostor. Projekt řeší bezpečnou distribuci energie, správu dobíjení a uživatelskou dostupnost.

Klíčové prvky:
  • Řízení inteligentního nabíjení jednotlivých slotů (BMS ochrana)
  • Návrh mechanického zamykání a uvolňování powerbanky
  • Koncept uživatelského rozhraní pro rychlé vypůjčení
Elektrotechnika Li-Ion & BMS Napájecí obvody Automatizace
IoT & Senzorika

Monitorovací IoT stanice (Arduino / ESP)

Projekt samostatné měřicí jednotky pro sledování teploty, vlhkosti a kvality vzduchu. Data jsou v reálném čase zpracovávána mikrokontrolérem a odesílána na přehledný displej nebo do webového rozhraní.

Klíčové prvky:
  • Integrace digitálních senzorů a mikrokontroléru
  • Návrh schématu a sestavení na kontaktním i plošném spoji
  • Programování logiky vyhodnocování naměřených limitů
Mikroelektronika Arduino / ESP Senzorika Hardware
Web & UI/UX

Osobní digitální vizitka & portfolio

Responzivní webová prezentace vytvořená v rámci předmětu Moderní technologie. Obsahuje interaktivní prvky (přepínání režimů, filtry dovedností), zabezpečení proti indexování a je hostována na GitHub Pages.

Klíčové prvky:
  • 100% responzivní design pro mobily i stolní monitory
  • Čistý HTML5, CSS3 a JavaScript bez zbytečných závislostí
  • Nasazení přes Git a GitHub Pages s noindex metadaty
HTML5 & CSS3 JavaScript GitHub Pages AI Pair Programming
